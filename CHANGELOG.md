# Changelog

## [1.0.0] — 2026-11-03

Первый стабильный релиз / First stable release.

### Добавлено / Added
- Компонент `feedwall` для InstantCMS 1.11.0: общая лента и стены пользователей и клубов в одном компоненте.
- Записи: текст, смайлы, #хэштеги, @упоминания, фото, аудио, голосовые, видео (YouTube, Vimeo, RuTube, VK, Facebook), превью ссылок, цветные фоны, опросы (с картинками), GIF.
- Анонимные записи, записи «только для друзей», публикация от имени пользователя (админ), закрепление на стене и в ленте.
- Реакции и лайки, комментарии с ответами, фото, GIF и голосом, репосты и кнопки «Поделиться», жалобы, скрытие записей, счётчик просмотров, карточка пользователя.
- Вкладки ленты: все, друзья, мои, популярное, обсуждаемое, просматриваемое; страницы тегов, «Понравилось», фото и музыки пользователя.
- Настройки приватности пользователя, гостевые записи с капчей, лимиты, время на редактирование.
- Реклама в ленте со статистикой показов и переходов, импорт RSS по крону, категории GIF, фоны, инструменты пересчёта и очистки.
- Модули `mod_feedwall_form`, `mod_feedwall_list`, `mod_feedwall_tags`; плагины `p_feedwall`, `p_feedwall_likes`; поиск; лента активности (cmsActions).
- Установщик с обновлением схемы (upgrade) и полным удалением; языки ru/en.
